# 180s Ahead / 60s Behind Buffer Policy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a fixed 180s ahead / 60s behind in-memory buffer for TS streams in `useMSEPlayer.ts`, with burst-fill-to-target then playback-speed pacing, and instant 180s disk-cache fill on seek.

**Architecture:** Disable mpegts.js native `autoCleanupSourceBuffer` and move the 60s behind eviction into the custom `sourceBufferQuotaGuard`. Raise the lazyLoad/IOController ceiling to 180s ahead. Extend the seek handler to use the VBR byte-time index and temporarily disable pacing so the backend `/stream` cache can saturate the SourceBuffer instantly. Keep the disk prebuffer and cold-start overlay unchanged.

**Tech Stack:** React, TypeScript, mpegts.js, Tauri, Rust, Vitest.

## Task 3: High-Bitrate Fallback (Shrink Behind Window)

**Files:**
- Modify: `src/hooks/useMSEPlayer.ts` inside `sourceBufferQuotaGuard` (around the eviction block, lines 3350-3400+)

**What & why:** If the total 240s window exceeds the browser SourceBuffer quota, keep 180s ahead and reduce the behind window to 30s or 15s. Detect pressure via `QuotaExceededError` and a heuristic byte budget.

- [ ] **Step 1: Add safe-byte budget helper near the top of the quota guard**

After the constants are declared (e.g., after line 3137 or inside the guard body), add:

```typescript

      const globalBitrateBps = (state.current.fileLength && mpegtsDurationRef.current)
        ? state.current.fileLength / mpegtsDurationRef.current
        : (state.current.fileLength && state.current.duration)
          ? state.current.fileLength / state.current.duration
          : 0;
```

If `mpegtsDurationRef.current` or `state.current.duration` are not in scope, use the longest available duration estimate (`mpegtsDurationRef.current || (window as any).__nobuf_ptsDuration || state.current.duration || 0`).

- [ ] **Step 2: Compute effective behind window before eviction**

Before the eviction block, add:

```typescript
        // High-bitrate fallback: if the full 180s/60s window exceeds the browser's
        // likely MSE budget, keep 180s ahead and shrink the behind window first.
        let effectiveKeepBehind = QUOTA_KEEP_BEHIND; // 60
        if (globalBitrateBps > 0) {
          const totalWindowSeconds = QUOTA_KEEP_AHEAD + QUOTA_KEEP_BEHIND; // 240
          const totalWindowBytes = totalWindowSeconds * globalBitrateBps;
          if (totalWindowBytes > SAFE_SOURCE_BUFFER_BUDGET_BYTES) {
            const aheadBytes = QUOTA_KEEP_AHEAD * globalBitrateBps;
            const remainingBudget = Math.max(0, SAFE_SOURCE_BUFFER_BUDGET_BYTES - aheadBytes);
            const maxBehindSeconds = Math.floor(remainingBudget / globalBitrateBps);
            if (maxBehindSeconds < 60) {
              effectiveKeepBehind = Math.max(15, Math.min(30, maxBehindSeconds)); // 60 → 30 → 15
            }
            if (effectiveKeepBehind !== QUOTA_KEEP_BEHIND) {
              diagLog(`[MPEGTS] High-bitrate fallback: behind window ${QUOTA_KEEP_BEHIND}s → ${effectiveKeepBehind}s (bitrate ${(globalBitrateBps/8/1024).toFixed(1)} KB/s)`);
            }
          }
        }
```

Update the eviction window from Task 2 to use the effective behind:

## Task 5: Seek Into Disk Cache — Instant 180s Fill

**Files:**
- Modify: `src/hooks/useMSEPlayer.ts` around `seekTo` (line ~5481) and `_mpegtsUnbufferedSeek` (line ~3969)

**What & why:** When the user seeks to a position where the next 180s are already on disk, compute the exact byte via the VBR index, disable interceptor pacing, and set the serve limit to `seekTime + 180` so the backend `/stream` cache can saturate the SourceBuffer instantly.

- [ ] **Step 1: Detect disk coverage in `seekTo`**

In `seekTo`, before calling `_mpegtsUnbufferedSeek`, add a flag for "seek to cached range":

```typescript
  const isSeekToCachedRange = (targetTime: number) => {
    const fileLen = state.current.fileLength || 0;
    const dur = mpegtsDurationRef.current || state.current.duration || 0;
    if (!shadowCacheRef.current || fileLen === 0 || dur === 0) return false;
    const startByte = findByteForTime(targetTime, byteTimeSamplesRef.current, dur, fileLen);
    const endByte = findByteForTime(Math.min(targetTime + 180, dur), byteTimeSamplesRef.current, dur, fileLen);
    const endByteClamped = Math.min(endByte, fileLen - 1);
    if (endByteClamped <= startByte || endByteClamped <= 0) return false;
    const run = shadowCacheRef.current.cachedRunFrom(startByte);
    return run !== null && run.end >= endByteClamped;
  };
```
